## 品牌与生产方式

- 插图中的 "ACKS" 品牌、Logo 和两个吉祥物角色，是作者本人的 OPC / IP，不是本书虚构的示例品牌。这一点会在第三章（给你的 OPC 一个名字）里对读者自然展开，第一章不需要额外解释。
- 品牌元素被有意注入每一张插图，作为内容被转载/盗用时的可识别印记。
- 生成模型：ChatGPT 内的 GPT Image 2.5。
- 生成方式：不是纯文本 Prompt，而是"文章内容梗概 + 吉祥物 / Logo 垫图（参考图）"的图生图工作流，所以单张图片没有可复现的独立文本 Prompt 存档。
